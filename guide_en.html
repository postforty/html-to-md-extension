📖 HTML to MD Saver User Guide

A powerful tool that lets you convert and translate any selected web page elements into clean Markdown documents with just a single click.

Basic Usage

  • Click the puzzle icon or the pinned HTML to MD Saver icon in your browser toolbar to open the popup.
  • Click the [Start Selecting] button.
  • Hover over the web page; when a dark orange dashed border highlights your desired element (paragraph, image, table, etc.), click it.
  • Markdown conversion (and translation) will run automatically and show a preview modal. Click [Download (Save as .md)] to save your file.

⌨️ Key Shortcuts & Gestures (Advanced Features)

🖱️ Left-Click & Drag (Instant Box Selection)
Hold down the left mouse button and drag a box across the page. All elements inside the box will be captured at once, and the Markdown preview modal will appear immediately.
This is extremely convenient for capturing product lists, multi-paragraph articles, and complex layouts in seconds.
Ctrl (or Mac Cmd) + Mouse Click (Multiple Individual Selection)
Used when you want to collect multiple scattered elements across the page into a single Markdown document.
Hold Ctrl (or Cmd) while clicking elements to lock them with a solid orange outline. Once all desired items are chosen, click the floating [Convert N Selected Elements] button at the bottom of the screen to merge and extract them.
ESC (Cancel Selection & Exit)
Whenever you want to exit element selection mode or reset multiple selections, simply press ESC to safely cancel and return to normal page browsing.

🌐 AI Translation Feature (Gemini)

Register your Google Gemini API Key in the extension settings (Options) to enable powerful AI translation.

  • Translated Only: Replaces the original text with a natural translation.
  • Original + Translated: Retains the original text and places the translated version directly below each paragraph in a blockquote. Great for language learning and reference!
