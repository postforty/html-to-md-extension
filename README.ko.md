# HTML to MD Saver (크롬 확장 프로그램)

[English](README.md) | **한국어**

웹 페이지에서 원하는 요소를 마우스로 클릭하거나 드래그하여 해당 영역을 추출해 **마크다운(Markdown, `.md`)** 파일로 즉시 다운로드하고 번역해 주는 크롬 확장 프로그램입니다.

---

## ✨ 주요 기능

- **🎯 직관적인 요소 선택:** 확장 프로그램을 실행하고 웹 페이지 위를 마우스로 이동하면 선택될 영역이 시각적으로 하이라이트됩니다.
- **🖱️ 마우스 영역 드래그 즉시 변환:** 마우스 좌클릭 후 드래그하여 범위를 지정하면, 영역 내 포함된 여러 요소들이 한 번에 캡처되어 **마크다운 미리보기 모달이 즉시 표시**됩니다.
- **🧩 개별 다중 선택 지원 (`Ctrl` + Click):** `Ctrl`(Mac은 `Cmd`) 키를 누른 상태로 개별 요소를 클릭하면 분산된 여러 개의 요소를 동시에 스크랩하여 하나의 파일로 병합할 수 있습니다.
- **📑 우클릭(드래그) 영역 추출:** 페이지 내 텍스트를 드래그하여 블록을 지정한 후 마우스 우클릭을 통해 원하는 영역만 빠르게 마크다운으로 추출할 수 있습니다. 복사 방지가 적용된 사이트에서도 매우 유용합니다.
- **⚡ 즉각적인 반응형 미리보기 & 클립보드 복사:** 요소를 선택하는 즉시 0.01초 만에 화면 중앙에 미리보기 모달이 오픈되며, 파일 다운로드뿐만 아니라 **[클립보드 복사]** 버튼으로 즉시 붙여넣을 수 있습니다.
- **🤖 AI 기반 자동 번역 (Gemini):** Google Gemini API와 연동하여 추출된 마크다운을 자동 번역합니다. 번역 중일 때는 모달 내에서 실시간 AI 로딩 스피너가 표시됩니다.
- **⚙️ Gemini 모델 ID 커스텀 지정:** 설정에서 기본 모델(`gemini-3.1-flash-lite`) 외에 사용자가 원하는 최신 모델(예: `gemini-3.5-flash`, `gemini-3.1-pro-preview` 등)을 직접 지정하여 사용할 수 있습니다.
- **🔄 서버 과부하(503/429) 자동 재시도:** API 호출 중 일시적인 서버 혼잡이 발생할 경우 최대 3회 지수 백오프로 자동 재시도하여 안정적인 번역 결과를 보장합니다.
- **🔀 유연한 번역 모드 선택:** 원본만 저장, 번역본만 저장, 원본+번역본 교차 저장 모드를 지원합니다.
- **🌐 다국어(i18n) 완벽 지원:** 한국어와 영어(English) UI를 지원하며, 시스템 언어 자동 감지 및 설정 화면에서 영구적인 수동 언어 선택이 가능합니다.
- **🔄 설정 기본값 복원 (Reset):** API Key는 안전하게 보존하면서 모델, 언어, 저장 방식을 원클릭으로 초기화할 수 있습니다.
- **🛡️ Shadow DOM & 최신 웹앱 완벽 지원:** Shadow Root(`shadowRoot`)로 캡슐화된 웹 컴포넌트(Lit, Angular, Polymer 기반 최신 웹앱 등) 내부의 텍스트 및 코드 블록까지 정확하게 탐색하고 추출합니다.
- **💬 실시간 상태 안내 토스트 & 단축키 격리:** 요소 선택 모드 시작 시 `(ESC: 취소)` 안내 토스트와 해제 시 알림 토스트를 화면 상단에 띄워 현재 상태를 명확히 인지할 수 있으며, `ESC` 키 입력 시 웹페이지 단축키와의 충돌을 완벽 차단합니다.
- **📁 로컬 HTML 파일(`file://`) 지원 & 권한 감지:** 웹사이트뿐만 아니라 로컬 PC에 저장된 HTML 파일도 마크다운으로 변환할 수 있으며, Chrome 보안 권한(파일 URL 액세스) 필요 시 친절한 안내를 제공합니다.
- **🛡️ 안전한 취소 모드 (`ESC`):** 영역 선택 중 언제든 `ESC` 키를 누르면 요소 선택 모드를 즉시 안전하게 종료할 수 있습니다.
- **📝 GFM(GitHub Flavored Markdown) 완벽 지원:** 표(Table), 취소선 등의 GFM 문법과 코드 블럭(`<pre>`, `<code>`)을 훼손 없이 ` ``` ` 펜스 코드 블럭으로 깔끔하게 유지합니다.
- **🔗 절대 경로 자동 변환:** 상대 경로(`.`, `/`)로 작성된 하이퍼링크와 이미지 주소를 클릭 가능한 절대 경로(Absolute URL)로 자동 변환하여 링크 깨짐을 방지합니다.

## 🚀 설치 및 사용 방법 (개발자 모드)

1. 이 저장소를 로컬 컴퓨터에 다운로드하거나 `git clone` 합니다.
2. 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력하여 **확장 프로그램 관리 페이지**로 이동합니다.
3. 우측 상단의 **'개발자 모드'** 토글 버튼을 켭니다.
4. 좌측 상단에 나타난 **'압축해제된 확장 프로그램을 로드합니다' (Load unpacked)** 버튼을 클릭합니다.
5. 다운로드한 `html-to-md-extension` 폴더를 선택하여 확장 프로그램을 등록합니다.
6. 마크다운으로 스크랩하고 싶은 웹 페이지로 이동합니다. (단, `chrome://` 내부 페이지나 크롬 웹스토어에서는 보안상 작동하지 않습니다.)
7. **[방법 1: 요소 선택 모드]** 확장 프로그램 아이콘을 눌러 **[요소 선택 시작]**을 클릭한 뒤 화면에서 원하는 영역을 클릭하거나 드래그합니다.
8. **[방법 2: 우클릭 드래그 모드]** 웹 페이지의 텍스트를 드래그한 뒤 마우스 우클릭을 하여 **[선택 영역 마크다운 변환]** 메뉴 중 원하는 모드를 클릭합니다.
9. 화면에 나타나는 **미리보기(Preview)** 창에서 결과를 확인하고 **[클립보드 복사]** 또는 **[다운로드]** 버튼을 클릭합니다!

## 📂 프로젝트 구조

- `manifest.json`: 크롬 확장 프로그램의 설정 파일 (Manifest V3, i18n 지원)
- `_locales/`: Chrome Web Store 및 브라우저 표준 로캘 메시지 (`ko`, `en`)
- `i18n.js`: 런타임 다국어(한국어/영어) 번역 사전 및 스토리지 연동 공통 모듈
- `popup.html` / `popup.js`: 확장 프로그램 팝업 UI 및 스크립트 주입 로직
- `options.html` / `options.js`: 환경 설정 페이지 (API 키, Gemini 모델, 기본 저장 방식, UI 언어 및 초기화)
- `guide.html` / `guide_en.html`: 한국어 및 영문 사용자 설명서
- `content.js`: 화면 요소/드래그 영역 추출, 하이라이트, 실시간 모달 UI 및 마크다운 변환 로직
- `background.js`: 컨텍스트 메뉴(우클릭) 생성, 다운로드 처리, Gemini API 통신 및 자동 재시도 워커
- `turndown.js`: HTML을 Markdown으로 변환해 주는 핵심 라이브러리
- `turndown-plugin-gfm.js`: 표(Table) 등의 부가 문법을 지원하는 GFM 확장 라이브러리

## ⚠️ 한계점 및 주의사항

- 크롬 확장 프로그램의 보안 특성상 페이지 내부에 삽입된 외부 `<iframe>` (예: 유튜브 영상, 외부 결제창, 소셜 위젯 등) 내부의 요소는 선택하거나 변환할 수 없습니다.
- 코드를 수정하신 경우 반드시 확장 프로그램 관리 페이지(`chrome://extensions/`)에서 새로고침(↻) 아이콘을 누르고, **테스트 중인 웹 페이지(F5)도 함께 새로고침해야** 수정된 스크립트가 정상적으로 반영됩니다.

## 📜 버전 히스토리 (Changelog)

### v1.5
- **⚡ 0ms 스마트 즉각 재진입 (광고/iframe 다수 포함 사이트 완벽 지원):** 조선일보 등 20~30개 이상의 광고 iframe이 존재하는 복잡한 포털/언론사 사이트에서 `ESC` 취소 후 [요소 선택 시작]을 다시 클릭했을 때 무반응이거나 지연되던 문제를 메인 프레임 스크립트 상태 초고속 감지(1ms) 및 직접 실행 방식으로 완전 해결 (0ms 딜레이 즉각 재진입)
- **💬 시각적 상태 안내 토스트 (Toast UI):** 요소 선택 모드 시작 시 `요소 선택 모드가 시작되었습니다. (ESC: 취소)` 안내 토스트 및 `ESC` 취소 시 `요소 선택 모드가 해제되었습니다.` 토스트를 화면 상단에 띄워 사용자 경험 대폭 개선
- **⌨️ 안전한 ESC 단축키 이벤트 격리:** `ESC` 키 입력 시 `preventDefault()` 및 `stopPropagation()`을 적용하여 웹페이지 본래의 단축키나 모달 닫기 이벤트와의 원치 않는 간섭 및 충돌 완벽 차단
- **📁 로컬 HTML 파일(`file://`) 지원 및 권한 감지:** 로컬 PC의 HTML 파일에서도 원활하게 스크랩할 수 있도록 사전 검증 로직을 추가하고, Chrome '파일 URL에 대한 액세스 허용' 권한이 비활성화되어 있을 때 친절한 가이드 알림 제공
- **🌐 신규 다국어 메시지 완벽 지원:** 추가된 토스트 및 권한 알림에 대한 한국어/영어(i18n) 사전 반영
